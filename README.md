# Reportes de montacargas
PWA para generar reportes de servicio, llevar pendientes (Hub) e historial, y enviarlos por WhatsApp.
Datos locales en el teléfono; respaldo opcional en Google Sheets (apps-script/Code.gs).

1. Subir a GitHub Pages: `./setup.sh` (o subir los archivos desde github.com y activar Settings > Pages).
2. Sheets: crear una hoja, Extensiones > Apps Script, pegar Code.gs, cambiar KEY, Implementar > Aplicación web (Ejecutar como: yo, Acceso: cualquiera).
3. En la app: pestaña Historial > pegar la URL /exec y la clave > "Guardar y subir todo".
